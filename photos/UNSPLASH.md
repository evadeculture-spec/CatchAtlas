# Fotografias Unsplash por barragem

Gerado a partir de `src/data/photos/unsplash.json`. Imagens servidas pelo CDN do Unsplash (hotlink), com crédito “Foto de X no Unsplash” e download registado via API.

- **local**: a descrição do autor no Unsplash nomeia esta albufeira.
- **região**: a descrição nomeia a zona ou o rio, mas não confirma a albufeira → rótulo “Imagem da região · local exato não confirmado”.
- **ilustrativa**: paisagem semelhante, não é esta albufeira → rótulo “Imagem ilustrativa · não é desta barragem”.

Nenhuma fotografia se repete entre barragens. Para substituir uma ilustrativa por uma fotografia real, use o pipeline (`npm run photos:*`); uma fotografia local publicada passa à frente automaticamente.
